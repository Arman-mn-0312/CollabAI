CollabAI — UI/UX Guidelines

1. Purpose

This is the visual and interaction source of truth for CollabAI. The uploaded Noupe template is the visual reference; CollabAI uses original branding, content, layouts, and interactions.

2. Design Direction

Modern, AI-focused, collaborative, clean, professional, friendly, spacious, responsive.

3. Color System

Primary Magenta: #D200D3 — main CTA, active AI states, links

Primary Dark: #940095 — hover/deeper accent

Dark: #0A0807 — main text, dark sections, navigation

Warm Peach: #FEE4D4 — hero/background surfaces

Soft Pink: #FFB6C5 — decorative gradients

Light Pink: #FDC6D1 — decorative surfaces

White: #FFFFFF — cards/light content surfaces

4. Typography

Use a clean modern sans-serif. Hero headings are large/bold; section headings large/semibold; card headings medium/semibold; body text readable; metadata small/muted.

5. Landing Page

Navbar → Hero → AI/Product preview → Feature cards → Three chat spaces → How it works → Final CTA → Footer.

Hero direction:
“Work together. Think together. Build together.”

6. Application Navigation

Desktop: Logo, Dashboard, Groups, Personal AI, Settings, profile menu.
Mobile: compact header/menu and touch-friendly navigation.

7. Dashboard

Show welcome message, user's groups, recent activity when available, Create Group CTA, and Personal AI entry point.

8. Group Workspace

Desktop shows two primary chat spaces side by side:

Group Member Chat

Group AI

Personal AI is separate.

Mobile switches between them with tabs.

9. Group AI

Initial sections: General, Frontend, Backend, Database, Testing, Research.
The active section uses the primary magenta accent.

10. Personal AI

Private to the current user. Recommended layout: conversation list + current conversation + New Chat + message composer.

11. Chat Components

Message list, user bubble, AI bubble, avatar, timestamp, composer, send button, loading, empty state, error state.

12. Buttons

Primary: filled magenta, white text, rounded.
Secondary: white/light surface, dark text, border.
Ghost: transparent, dark or magenta text.
All need consistent hover/focus states.

13. Cards

Rounded corners, white/warm neutral surfaces, comfortable padding, subtle border/shadow, clear hierarchy.

14. Responsive Design

At smaller widths: navigation collapses, two-column chat becomes tabbed, cards stack, sidebars become drawers, controls remain touch-friendly.

15. Accessibility

Keyboard navigation, visible focus states, accessible labels, sufficient contrast, semantic HTML, clear errors.

16. UI Ownership

Arman: Login/Register, Profile, Personal AI, shared UI support.
Saniya: Group management, Group workspace, Member chat, Group AI workspace.
Shared: Landing page, Dashboard, design system, shared components, final integration.

17. UX Principles

Keep primary actions obvious.

Avoid feature overload.

Keep group and AI interactions visually connected.

Preserve context when switching sections.

Show loading, empty, success, and error states.

Design mobile intentionally.

18. Reference Rule

Use the Noupe template for color direction, large typography, rounded cards, hero composition, CTA treatment, AI/chat presentation, and responsive navigation. Do not copy its branding, exact content, or exact visual assets.
